# Туториал — бэклог пунктов (накопитель)

> **Зачем файл:** оверлей-слой туториала пока НЕ построен. Любую новую фичу с
> неочевидным жестом сюда **дописываем формулировкой** — когда сделаем слой
> туториала (отдельный следующий тикет), он соберётся из этих пунктов.
> Правило: жесты объясняем в туториале, **на сами карточки подсказки не плодим**
> (кроме коротких first-N-times хинтов, которые уже есть).

Каждый пункт: **триггер** (когда показать), **что показать**, **где в коде живёт жест**.

---

## 1. Свайп карточки-результата → дальше  *(сделано, нужен туториал)*
- **Триггер:** первый показ результата в практике (AI ручной режим или Режим разговора).
- **Что показать:** «Смахни карточку влево или вправо, чтобы перейти к следующей. В AI-режиме направление неважно — оценка уже зафиксирована.»
- **Код:** `onCardUp`/`canSwipe` в [Training.tsx](frontend/src/pages/Training.tsx). Сейчас есть on-card хинт `practice.hintSwipeNext` первые 8 раз.

## 2. Режим разговора: Слушай → Говори → свайп  *(сделано, нужен туториал)*
- **Триггер:** первое включение тумблера «Режим разговора».
- **Что показать:** 3 шага — «**Слушай** реплику (микрофон приглушён) → загорается **Говори** (изумрудное кольцо) — отвечай вслух → видишь оценку и **смахиваешь** дальше». Авто-перехода нет.
- **Код:** hands-free loop + `hfStage` в [Training.tsx](frontend/src/pages/Training.tsx), стадии `cue/listen/score`.

## 3. Сильное нажатие на бэч → меню  *(в работе — см. [TZ-batch-management.md](TZ-batch-management.md))*
- **Триггер:** первый вход в Библиотеку / Learning после релиза фичи (или первое «зависание» пальца на карточке без открытия меню).
- **Что показать:** «**Задержи палец** (сильное нажатие) на бэче — откроется меню: добавить **в активные** (в практику) или **на траекторию обучения**, и убрать оттуда.»
- **Код:** `useLongPress` + `BatchActionSheet` (по ТЗ).

## 4. (раньше отложено) Полноэкранный гайд жестов практики
- Из ТЗ карточки практики: общий первый онбординг жестов колоды (флип non-AI, свайп, микрофон). Кандидат стать «экраном 1» слоя туториала.

## Идея реализации слоя (черновик, не сейчас)
- Лёгкий `TutorialProvider`: ключи показанных шагов в localStorage (`ee-tut-{key}`), показываем coachmark/споты один раз.
- Контент — из этого файла. Шаги адресуются по `key` (`swipe-next`, `talk-mode`, `batch-longpress`, …).
- Точка входа: при первом достижении триггера `showTutorial(key)`; «Понятно» → пометить показанным.
