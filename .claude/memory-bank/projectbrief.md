# Project Brief: english

> **Foundation document — immutable. Меняется редко, только при пересмотре scope.**

## Что это
**Executive English** — персональный mobile-first PWA-аудиотренажёр для отработки бизнес-английского
*говорения*. Куратор-составленные «батчи» паттернов (executive-фразы) учатся через **3-урочный flow**:
(1) мнемоническая основа (история-каркас якорей) → (2) фразы (якорь→фраза) → (3) тесты (устный recall
с оценкой). Аудио рендерится **gapless** в один WAV, чтобы паузы переживали блокировку экрана iOS
(нет JS-таймеров). Прод: `https://executive-english.net` за cookie-гейтом.

## Зачем (бизнес-цель)
Основателю (Алексей, non-native) нужна естественная executive-коммуникация на английском — питч,
переговоры, несогласие, ответы под давлением. Готовые тулы не дают active-recall именно кураторских
executive-паттернов с офлайн-аудио и оценкой устного воспроизведения. Это личный инструмент, чтобы
довести нужные фразы до автоматизма «в моменте».

## Пользователи
**Один пользователь — Алексей.** Используется с iPhone (PWA, наушники, метро, экран заблокирован).
Не продукт для рынка; приоритет — личная польза и премиальное ощущение, а не масштаб/мультиюзер.

## Scope (что внутри)
- Импорт батчей фраз (paste → детерминированный парсер + LLM-фолбэк → approve → SQLite).
- Gapless офлайн-аудио сессии (Active Recall по умолчанию + Listening), кэш в браузере.
- 3-урочный learning flow + 3-этапный финальный экзамен (пересказ / мнемо-основа / якорь) с оценкой.
- Оценка устного recall: STT (`gpt-4o-mini-transcribe`) + LLM-скоринг (gate → nano/mini).
- Раздел «Обучение» — карта-путь (Duolingo-стиль, без геймификации) + адаптивный возврат.
- Премиальный UI «тихая премиальность» (Apple Music/Fitness+, фирменный зелёный) — см. `DESIGN.md`.

## Anti-scope (что точно НЕ делаем)
- Мультиюзер / аккаунты / регистрация / соц-функции.
- Геймификация: очки, стрики, жизни, награды-бейджи (жёсткая граница Алексея).
- Общий вокабуляр / не-английский / не-executive контент.
- Публичные стоимостные эндпоинты (TTS/LLM — только из admin/cron, наружу статика + плеер).

## Success criteria
- Алексей реально открывает приложение и тренируется с телефона (привычка).
- Устный recall паттернов улучшается (растёт средний балл в уроках 2–3).
- Ощущается как премиальный Apple-продукт, а не «веб-форма».
- Аудио-паузы работают при заблокированном экране iOS (ключевой технический критерий).
